# 豆包视频「真·无水印」下载（逐像素、保留原画面、零 logo）

> 网页版工具受限于纯静态架构，只能做「裁剪遮挡」水印。要拿到**逐像素、保留原画面、零 logo** 的无水印视频，用本方案——它走豆包的**登录态**接口，效果和豆包网页播放器一致。

## 原理

豆包视频的无水印源被锁在**登录态接口**后面：

```
get_video_model → video_model.fallback_api
                → 删除 logo_type / force_fids 参数
                → FPLAY AES-CBC 解密（SHA-512 KDF）
                → 真实无水印直链
```

这一步只能在你**已登录豆包的浏览器**里完成（需要你的登录 cookie）。

## 使用方法（约 2 分钟）

1. 安装浏览器扩展 **Tampermonkey**（油猴）：
   - Edge/Chrome 应用商店搜「Tampermonkey」安装
2. 新建脚本，把 [`tools/doubao-nomark.user.js`](../tools/doubao-nomark.user.js) 的内容粘贴进去保存
3. 用**已登录豆包**的浏览器，打开你要的视频分享页（`https://www.doubao.com/video-sharing?...`）
4. 页面底部会出现按钮「⬇️ 下载真·无水印视频」，点一下即可下载

## 效果

- 逐像素无水印，画面完整不裁剪、无 logo
- 下载为 mp4
