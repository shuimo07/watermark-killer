# 豆包视频「真·无水印」下载（逐像素、保留原画面、零 logo）

> 网页版工具受限于纯静态架构，只能做「裁剪遮挡」水印。要拿到**逐像素、保留原画面、零 logo** 的无水印视频，用本方案——它走豆包的**登录态**接口，效果和豆包网页播放器一致。

## 原理

豆包视频的无水印源被锁在**登录态接口**后面：

```
get_video_model → video_model.fallback_api
                → 删除 logo_type / force_fids 参数
                → FPLAY AES-CBC 解密（SHA-512 KDF）
                → 真实无水印直链
```

这一步只能在你**已登录豆包的浏览器**里完成（需要你的登录 cookie）。

## 使用方法（推荐：书签，免装扩展）

1. 浏览器新建一个书签，名称随意，**网址填这一行**（整行复制粘贴）：

   ```
   javascript:(function(){var s=document.createElement('script');s.src='https://shuimo07.github.io/watermark-killer/tools/doubao-nomark.user.js';document.body.appendChild(s);})();
   ```

2. 用**已登录豆包**的浏览器打开视频分享页（`https://www.doubao.com/video-sharing?...`）
3. 点一下刚建的书签 → 页面底部出现「⬇️ 下载真·无水印视频」按钮 → 点它下载

> 书签只是加载我们仓库里的脚本，脚本在你的豆包登录态里运行，**cookie 全程不离开浏览器**。

## 使用方法（备选：油猴脚本）

1. 安装浏览器扩展 **Tampermonkey**（Edge/Chrome 应用商店搜「Tampermonkey」）
2. 新建脚本，把 [`tools/doubao-nomark.user.js`](../tools/doubao-nomark.user.js) 内容粘贴保存
3. 打开豆包视频分享页（已登录），页面底部出现按钮，点一下下载

## 效果

- 逐像素无水印，画面完整不裁剪、无 logo
- 下载为 mp4
