# P7：本地文件自动去水印（ffmpeg.wasm delogo → mp4）设计与实现

> 版本：v0.3.0 · 2026-08-16
> 目标：把豆包等 AI 生成的视频文件**丢进网页**，自动全面检测并去除水印，输出**无水印 mp4**。全程浏览器本地处理，视频不上传任何服务器。

---

## 1. 需求背景

- 豆包分享链接的公开接口只能拿到**带水印成片**（无水印源需登录态，平台限制）。
- v0.2.0 的「裁剪」方案会牺牲画面构图与分辨率；MediaRecorder 重编码输出质量与格式受限。
- 用户诉求：**直接拖入视频文件 → 自动检测水印 → 去除 → 输出 .mp4**。

## 2. 方案选型（参考开源项目调研）

| 项目 | 方案 | 是否可用于纯前端 Pages |
|---|---|---|
| [minknown/watermarkRemove](https://github.com/minknown/watermarkRemove) | PaddleOCR 文本识别 + Florence-2 生成式修复（AI inpainting） | ❌ 需 GPU/本地 Python |
| [Purfview/InpaintDelogo](https://github.com/Purfview/InpaintDelogo) | FFmpeg delogo 滤镜插件（插值填补） | ✅ 思路借鉴：**delogo 滤镜** |
| [HGStyle/ffmpeg-online](https://github.com/HGStyle/ffmpeg-online) / [skyjiang/FFmpeg-Online](https://github.com/skyjiang/FFmpeg-Online) | ffmpeg.wasm 在线处理 | ✅ 技术栈借鉴：**ffmpeg.wasm 自托管** |

**结论**：采用 **ffmpeg.wasm（@ffmpeg/core 0.12.6 单线程版）自带 delogo 滤镜 + libx264/aac 编码**，实现插值式去水印与 mp4 输出；水印位置用**抽帧时间维分析自动检测**（纯 JS，无需模型），并支持手动微调兜底。

## 4. 水印自动检测算法（detect.js）

原理：水印是**静止叠加**，画面在动。

1. **抽帧**：等间隔抽 8 帧（覆盖全片），缩放到工作分辨率（高 360px）。
2. **时间维统计**：逐像素算均值与标准差。半透明水印 `α·W + (1-α)·C(t)` 的方差被压缩为 `(1-α)²·var(C)`。
3. **关键判别——相对方差**：像素时间方差 / 邻域平均时间方差（盒式模糊）的比值 < 0.55 → 相对压缩 → 疑似水印。静止场景整个画面方差都低，比值≈1，不误报。
4. **边缘增强**：均值帧 Sobel 梯度 > 阈值 → 文字/logo 结构（静止背景平坦）。
5. **形态学**：膨胀连笔画 → 连通域外接框 → 尺寸过滤（0.06%~18% 面积）→ 外扩 → 映射回原分辨率。
6. **兜底**：全部没检出时检查四角常用水印位（仅当该角落时间方差也低时采纳）。

纯函数 `computeWatermarkBoxes(frames, w, h)` 可在 Node 直接单测（`tools` 验证通过）。

## 5. 去水印管线（ffmpeg.js）

```
ffmpeg -i input.mp4 \
  -vf "delogo=x=..:y=..:w=..:h=..,delogo=..." \   # 每框一个 delogo，串联
  -c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -movflags +faststart \
  -y output.mp4
```

- **delogo**：用周围像素插值填补水印区域（非裁剪、非模糊补丁），保留完整画面。
- **输出**：H.264 + AAC 标准 mp4，`+faststart` 便于网页播放。
- **加载**：优先同仓库 `vendor/ffmpeg/`（GitHub Pages 自托管，国内可访问）；失败回退 jsDelivr CDN。均以 blob URL 包装（跨域 Worker import 限制）。
- **进度**：ffmpeg `progress` 事件 → 百分比 + 已处理秒数；`log` 事件 → 日志面板。
- 引擎实例懒加载并缓存；每次运行挂独立 log/progress 监听，跑完即卸载（防回调堆积）。

## 6. 交互设计（filewm.js）

1. 点击/拖入视频（≤600MB 提示，类型校验 mp4/mov/webm/mkv…）。
2. 加载元数据 → 自动检测 → 画布显示蓝色水印框。
3. 微调：拖框移动、拖角/边缩放、点击空白新建框、清空、重新检测。
4. 一键去水印 → 进度条 + 日志 → 预览 → 下载 `原名_去水印.mp4`。

## 8. 合规与边界

- 仅去除用户拥有合法使用权内容的水印；视频全程本地处理不上传。
- 检测基于「静止+文字边缘」假设：动态/旋转/极低透明度水印可能需手动框选；delogo 对半透明静态水印效果最佳。
- 大文件/高分辨率在低配设备可能较慢（单线程 wasm），建议 ≤1080p、≤2 分钟。
