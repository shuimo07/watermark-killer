## 4. 接口文档（逆向所得）

### 4.1 登录
- `POST https://api-sy.yuantujun.com/user/login`
- 入参：`wx.login()` 的 `code`、`userType`、`inviter`…
- 返回：`openId`、`token`、`isVip`（存储于 globalData.user）

### 4.2 核心解析
- `POST https://parse.yuantujun.com/miniParse`
- 入参：`{ url, openId, token, isVip, platform, sign }`
- `sign = md5(url + openId + token)`（header 也带 `sign`）
- 错误码 `500204` → token 失效 → 重新登录重试
- **注意：解析接口地址实际是远端配置的**（`api_root/api/index/index2` 返回 `jiexiurl` / `liveurl`），小程序内 base 地址可被服务端随时更换

### 4.3 远端配置
- `GET {api_root}/api/index/index2` → `{ jiexiurl, liveurl }`（解析地址）
- `GET {api_root}/api/index/index3` → `{ config: { jiexi_ad_num } }`（广告频控）

### 4.4 其他
- `POST {fixHost}/api/inpainting`、`/api/uploadImage`、`GET /api/getMediaCheckResult?traceId=`
- `GET https://api-sy.yuantujun.com/member/useBean`
- `POST https://parse.yuantujun.com/admin/uploadErrMsg`（错误上报）

### 4.5 结果数据模型（parse-result 页）
```
{
  images: string[],      // 图集 URL 列表
  desc: string,
  videoUrl: string|null, // 无水印视频直链
  cover_url: string,
  title: string,
  downurl: string,
  type: "video" | image 类
}
```
下载：`wx.downloadFile({url: videoUrl, header: {Range: "bytes=0-…"}})` → 保存相册；图集逐张 `saveImageToPhotosAlbum`。

## 5. 复刻映射（网页端可行性）

| 原功能 | 网页端复刻 | 实现方式 |
|---|---|---|
| 粘贴链接解析（抖音/快手/微视/微博/淘宝） | ✅ 核心 | 自研平台适配器 + CORS 代理（原后端需微信登录，无法复用） |
| 视频/图集预览 | ✅ | HTML5 video / 图片墙 |

| 敏感检测 | ➖ 降级 | 本地关键词过滤或不做 |
| 会员/豆 | ➖ | 网页版移除（免费） |

| 客服引流 | ✅ | 替换为邮箱/QQ/公众号 |

## 6. 关键结论

1. **原解析后端不可复用**：`miniParse` 依赖微信 `wx.login` 的 openId/token 与 md5 签名，且接口地址可被服务端远端更换——GitHub Pages 纯前端无法也不应调用。
2. **复刻路线 = 自研解析层**：按平台实现「分享文案 → 提取 ID → 通过公开接口/CORS 代理拿无水印直链」。
3. **UI 风格参考**：主色 `#005bc1`、tabBar「首页/历史记录」、自定义导航、解析结果页 tab（视频/图集）、保存/复制按钮。
4. **需用户确认**：缓存包品牌为「字幕斩」，若目标是独立应用「水印斩」，请在 PC 微信打开一次后再抓取一次缓存。
