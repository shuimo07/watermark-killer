# 部署豆包真·无水印后端（Cloudflare Worker）

> 目的：网页版也能点一下就拿到**逐像素、保留原画面、零 logo** 的无水印视频。
> 原理：Worker 用你存的豆包登录 cookie 走登录态接口 + FPLAY 解密，返回真·无水印直链。

## ⚠️ 安全须知（务必读）

1. **cookie 是你的账号凭证**，等同于把你的豆包登录态托管在 Worker 上
2. cookie 会以 **Secret（加密环境变量）** 形式存在 Cloudflare，**不进入代码、不进 git、不发聊天**
3. 任何拿到你 Worker 地址的人都可能借它使用你的豆包登录态——请只自己用、勿公开分享地址
4. 若担心账号风险：建议用**备用/小号**登录豆包，或定期更换 cookie

## 部署步骤（约 5 分钟）

### 1. 注册 Cloudflare
打开 https://dash.cloudflare.com/sign-up 注册免费账号（已有则登录）。

### 2. 创建 Worker
1. 控制台左侧 **Workers & Pages** → **Create** → **Worker**（模板任选）
2. 把编辑器里代码**全部删除**，粘贴 [`tools/doubao-worker.js`](../tools/doubao-worker.js) 的完整内容
3. 点 **Deploy** 部署

### 3. 获取你的豆包 cookie
1. 用**已登录豆包**的浏览器打开 https://www.doubao.com
2. 按 `F12` 打开开发者工具 → **Console（控制台）** 标签
3. 粘贴并回车：`document.cookie`
4. 复制输出的一整串（形如 `sessionid=...; ttwid=...`）

### 4. 把 cookie 存为 Secret（关键，不要贴到别处）
1. 回到 Worker 详情页 → **Settings（设置）** → **Variables and Secrets**（变量与机密）
2. 点 **Add** → 类型选 **Secret**，名称填 `DOUBAO_COOKIE`，值粘贴你复制的 cookie
3. 保存并**重新 Deploy**

### 5. 拿到 Worker 地址
部署后你会得到一个地址，形如：
`https://your-name.your-subdomain.workers.dev`

### 6. 接入网页版
1. 打开 https://shuimo07.github.io/watermark-killer/
2. 进「问题」页底部，把 Worker 地址填进 **「真·无水印后端」** 输入框保存
3. 解析豆包视频后，结果页会出现 **「✨ 真·无水印」** 按钮，点一下即可下载逐像素无水印视频

## 验证

浏览器直接访问：`https://<你的worker>.workers.dev/?video_id=v0269cg10004d9v2uga7dld8dlfmap30`
返回 `{"code":0,"url":"https://..."}` 即成功；返回 `登录态失效` 说明 cookie 过期，需重新获取更新 Secret。
